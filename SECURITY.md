# Security Policy

## Reporting a Security Bug

We take security seriously. If you discover a security vulnerability in repoan, please report it privately via email to security@example.com (replace with your email).

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We will acknowledge your report within 48 hours and provide a timeline for a fix.

## Responsible Disclosure

We ask that you follow responsible disclosure practices:
- Do not disclose the vulnerability publicly until a fix is available.
- Give us reasonable time to investigate and resolve the issue.

## Supported Versions

Only the latest stable release of repoan is supported with security updates.
